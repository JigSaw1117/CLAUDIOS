Cada barra representa |βᵢ| — el valor absoluto del coeficiente tras la estandarización. A mayor longitud, mayor influencia sobre el log-odds de potabilidad.

Función Objetivo — Regresión Logística Binaria
Z = β₀ + Σ βᵢ · zᵢ     donde     zᵢ = (xᵢ − μᵢ) / σᵢ

σ(Z) = 1 / (1 + e−Z)  =  P(potable | x)

ŷ = 1 (Potable)   si   σ(Z) ≥ 0.5  ·  β₀ = −0.00073

Entrenado minimizando la Log-Loss (Entropía Cruzada Binaria):
ℒ(β) = −(1/N) Σ [ yᵢ · ln(pᵢ) + (1−yᵢ) · ln(1−pᵢ) ]

Intercepto β₀ = −0.00073 es el log-odds base cuando todas las variables están en su media de entrenamiento (zᵢ = 0). Cada coeficiente βᵢ indica cuánto sube o baja el log-odds por cada desviación estándar de la variable.

La función Sigmoide σ(Z) mapea cualquier valor real Z ∈ (−∞, +∞) a una probabilidad en (0, 1). Cuando Z = 0, σ = 0.5 (umbral de decisión).

Outliers Conservados — son lecturas reales de parámetros fisicoquímicos extremos, no errores de medición.
